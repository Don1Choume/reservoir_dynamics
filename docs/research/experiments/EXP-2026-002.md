# 実験記録: EXP-2026-002

実行日: 2026-07-30  
状態: 成功。既存の入力依存ESP・multistability理論のローカル再現。

## 1. 問い

スカラーtanhリザバー

\[
x_{t+1}=\tanh(a x_t+b u_t)
\]

について、次の三つを数値的に区別できるか検証した。

1. \(|a|<1\) による大域的収縮の十分条件
2. 一つの応答軌道に沿った負の条件付きLyapunov指数
3. 複数初期状態が同一の入力駆動応答へ収束するreplica同期

中心となる反証対象は「条件付きLyapunov指数が負なら、入力応答は大域的に
一意である」という過剰な解釈である。

## 2. 対応する主張

- `C-RC-001`: replica距離は入力条件付き再現性の観測量になる
- `C-RC-005`: 負の局所条件付き指数だけでは大域的一意性を保証しない
- `C-RC-006`: 大域的収縮条件の外側でも共通入力による同期が起こり得る
- `H-RC-001`: タスク性能との関係は本実験では未検証

## 3. 事前規定

- recurrent gain \(a\): `0.6, 1.0, 1.2, 1.5`
- input gain \(b\): `0.0, 0.5, 2.0, 4.0`
- input: seed `20260730` の一様分布 \(U[-1,1]\)
- steps: 2500
- washout: 500
- initial states: `-2, -1, 0, 1, 2`
- replica判定窓: 最後の100時刻
- 同期判定: tail RMS distance \(\le 10^{-8}\)
- derivative floor: \(10^{-300}\)
- randomness: 入力生成のみ。同じ入力列を全条件・全replicaで共有

有限時間条件付き指数は、参照軌道について

\[
\widehat\lambda_c
=
\frac{1}{T-W}\sum_{t=W}^{T-1}
\log\left(
\max\left[
|a|(1-x_{t+1}^2),10^{-300}
\right]
\right)
\]

で評価した。

### 結果A: 負の局所指数は大域的一意性を保証しない

\(a=1.2,b=0\) では

- \(\widehat\lambda_c=-0.386334<0\)
- tail replica RMS \(=0.931358\)

となった。参照軌道の近傍では摂動が減衰するが、異なる符号の初期状態は
異なる安定固定点へ収束する。従って、局所条件付き指数だけでは複数の安定
応答の共存を検出できない。

\(a=1.5,b=0\) でも同じ分離が生じた。

### 結果B: 大域収縮条件は必要条件ではない

\(a=1.2\) と \(a=1.5\) は \(|a|<1\) を満たさない。それでも今回の共通入力
では \(b\ge0.5\) の全条件でreplica距離が数値精度上ゼロになった。

入力により軌道がtanhの飽和領域へ移動すると、局所微分
\(|a|(1-x_{t+1}^2)\) が小さくなり得る。従って、自律系の大域的Lipschitz
上界だけでは入力駆動応答を完全には分類できない。

### 結果C: \(a=1,b=0\) は有限時間判定に敏感である

\(\widehat\lambda_c=-0.001205\) とほぼ中立で、tail replica RMSは
0.034976だった。ここでは有限時間の同期閾値だけで漸近的一意性を判断せず、
観測時間感度を調べる必要がある。

## 7. 証拠境界

### ローカル再現

- 負の局所条件付き指数と非同期replicaが同時に存在した。
- 大域収縮保証の外側で共通入力によるreplica同期を観測した。

### 推論

- 高次元RNNでも、top conditional Lyapunov指数だけでなく、複数初期状態、
  echo index、吸引域を併用すべきである。

### 未検証

- 入力gain 0.5が一般的な同期閾値であること
- 異なる入力分布、seed、高次元系での再現性
- 同期・非同期領域と計算能力、記憶能力の関係

## 8. 論文化への寄与

この結果は既存のinput-specific ESPとmultistability理論に整合し、単独では
新規性がない。ツールが局所安定性と大域的一意性を混同しないことを示す
ground truthとして利用する。

次の検証では、多次元tanh RNNについてrecurrent gain、input gain、seedを
掃引し、条件付きLyapunov指数、replica同期、linear memory curveを同時に
測定する。
