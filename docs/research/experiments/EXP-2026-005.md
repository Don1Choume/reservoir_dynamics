# 実験記録: EXP-2026-005

実行日: 2026-07-30  
状態: 成功。事前登録した4判定はすべて成立。

## 1. 問い

機能coreと可塑reserveを分けたtanh RNNで、

1. reserve-only更新はfeedbackがなければcore機能を厳密に保存できるか
2. 有限feedbackによるcore変化は決定論的上界内に収まるか
3. 未使用reserveは独立な新規入力記憶を獲得できるか
4. 同じ探索予算・同数の可塑parameter枠をcore側に置く対照より、core保持と
   新規容量をPareto改善できるか

を検証した。

これは「脳に実際のreserve blockが存在する」という実証ではない。可塑的余剰
が機能し得る構成的十分性と、今後反証可能な測定量を作るground-truth実験で
ある。

## 2. 事前規定

- trial seed: 201から230までの30 seed
- core/reserve dimension: 4/4
- core recurrent gain: 0.6
- core input gain: 0.75
- reserve-to-core feedback gain: 0, 0.02, 0.05, 0.1
- candidate `(reserve recurrent gain, input gain)`:
  `(0.3,0.25)`, `(0.3,0.75)`, `(0.6,0.25)`, `(0.6,0.75)`,
  `(0.9,0.25)`, `(0.9,0.75)`
- calibration: washout 50、train 200、test 100
- independent evaluation: washout 100、train 400、test 200
- maximum delay: 6
- ridge: \(10^{-8}\)
- bootstrap: seed再標本化、2,000 resamples、95%区間

core入力とnovel入力は独立な \(U[-1,1]\) とした。candidate選択には
calibration系列だけを使い、結果は独立evaluation系列で測った。

## 3. 公平な対照

### protected update

学習前に0だったreserveの対角再帰重み4個とnovel入力重み4個を可塑枠とした。
core parameterは固定した。

### entangled update

coreの対角再帰重み4個とnovel入力重み4個を可塑枠とし、reserveは未使用と
した。最適gainが学習前値と一致するseedでは、再帰重みの実変化は0になる。

両群は、

- 可塑parameter枠数: 8
- candidate数: 6
- calibration系列
- readout形式
- evaluation系列

を一致させ、それぞれ独立にnovel容量を最大化するcandidateを選んだ。

protected群は `(0.6,0.25)` を25 seed、`(0.3,0.25)` を5 seedで選択した。
entangled群は `(0.3,0.75)` を6 seed、`(0.6,0.75)` を16 seed、
`(0.9,0.75)` を8 seedで選択した。

## 4. 事前判定

1. `exact_zero_feedback_protection`:
   feedback 0の全seedでcore最大偏差 \(10^{-12}\) 以下かつcore retention 1。
2. `reserve_acquisition`:
   protected novel容量改善の対応付き95%区間下限が1を超える。
3. `finite_feedback_bound`:
   全seed、全feedback、全時刻で理論上界違反がない。
4. `protected_pareto_advantage`:
   protected minus entangledのcore retention差とnovel容量差の95%区間下限が
   ともに0を超える。

## 5. 理論上界

学習前後のcore距離を \(D_t\)、reserve距離上界を \(\overline R\) とすると、

\[
D_{t+1}
\le
L_cD_t+L_f\overline R,
\]

\[
D_t
\le
L_c^tD_0
+
L_f\overline R
\frac{1-L_c^t}{1-L_c}.
\]

今回は \(L_c=0.6\)、学習前reserveは0、tanh出力から
\(\overline R=1\) とした。従って長時間上界は \(2.5L_f\) である。

証明は
[機能coreと可塑reserveの保護条件](../theory/core-reserve-protection.md)
に記録した。

## 8. 解釈

### 8.1 「余剰」の構成的十分性

未使用reserveをデータで選んだparameterへ更新すると、既存core軌道を全く
変えずに独立入力の線形記憶容量を追加できた。全状態の軌道と機能レパートリー
は変化するが、core readoutから見た機能同値類は保存される。

これは「生得的core＋学習余地」が数学的に両立可能であることの構成例である。
生物がこの構造を採用していることや、進化がこれを選んだことの証拠ではない。

### 8.2 保護は二値ではなくcoupling budgetである

feedbackを0.02、0.05、0.1と増やすとcore retentionは単調に
0.9726、0.9000、0.7978へ低下した。完全分離だけでなく、許容忘却に応じた
feedback norm budgetとして設計できる。

### 8.3 raw parameter余剰だけでは足りない

同じ総状態次元、同じ可塑parameter枠数、同じ候補数でも、coreへ新規機能を
上書きした群は新規容量もprotected群より低く、core retentionもほぼ失った。
「未使用parameterがある」だけでなく、既存機能への力学的couplingを制御する
必要がある。

## 9. 証拠境界

### 証明・ground truth

- block-triangular系でreserve-only更新がcore因子を厳密保存する。
- 収縮coreと有界reserveに対するfeedback摂動上界。
- 今回の有限軌道は全時刻で上界を満たした。

### ローカル再現

- 4+4次元の対角tanh系、30 seedで新規容量とcore保持をPareto改善した。
- feedback増加に伴うcore retention低下を観測した。

### 未検証

- 多重安定な非収縮coreと吸引域境界の保存
- 非対角、疎、modular、spiking、学習済みRNN
- random mask、OGD、EWC、replayとの公平比較
- 8個の可塑重みはblockごとの共通gainで束縛され、実効探索次元は2である
- task数を増やしたときのreserve枯渇とmodule再利用
- 発生規則が保護maskを自発形成するか
- 生物connectomeでfeedback norm budgetが成立するか
