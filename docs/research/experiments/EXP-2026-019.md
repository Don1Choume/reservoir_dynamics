# EXP-2026-019: 誤分割がcertificate・計算量・固定予測へ与える機能影響

状態: development前事前登録  
登録日: 2026-08-08  
対応仮説: `H-RC-008`, `H-RC-007`, `H-BIO-004`

## 1. 問い

EXP-2026-018で陽にした最大affinity-gap分割の保証半径を越え、推定partitionが
真partitionと異なるとき、同じ摂動後RNNに対するcomponent profile、因子化
certificate、局所列挙計算量、EXP-2026-016固定predictorはどの程度変化するか。

重み摂動によるtask自体の変化と、同じ重みを異なるpartitionで解析することによる
誤差を分けるため、各摂動後重みをoracle partitionと推定partitionの双方で評価し、
結合後task trajectoryは一度だけ生成して共有する。分割推定にはtask、attractor、
readout、oracle labelを使用しない。

## 2. 既存研究との対応

- External equitable partitionではindicatorが結合作用素の不変部分空間を張るため、
  quotient dynamicsが元のnetwork dynamicsを表せる。従って構造partitionが
  動力学的縮約として正しいには、単なるcommunity密度以上の不変性条件が要る。
  Schaub et al. (2016), <https://arxiv.org/abs/1608.04283>
- Entrogramは同じnetworkにも異なる時間尺度またはMarkov性を保存する複数の
  coarse grainingがあり得ることを示す。本実験は単一の「真の機能分割」を一般に
  仮定せず、生成partitionを構成上の参照値として用いる。
  Faccin et al. (2018), <https://arxiv.org/abs/1711.01987>
- Coarse measurementからのcommunity回復には観測過程とgraph構造に依存する
  recovery条件が必要である。本実験は統計的一般回復ではなく、固定した7次元
  generatorと最大gap推定器の機能影響を扱う。
  Ghoroghchian et al. (2021),
  <https://proceedings.mlr.press/v130/ghoroghchian21a.html>

## 3. 数学的事前固定

### 3.1 任意partitionに対するcertificateの安全性

座標の任意partitionを \(P=(I_1,\ldots,I_m)\) とし、

\[
L^P_{ij}=\max_{r\in I_i}\sum_{c\in I_j}|W_{rc}|,
\qquad
\ell_i^P=\sum_{j\ne i}L^P_{ij}
\]

とする。tanh状態は \([-1,1]^n\) にあるため、block \(i\) へ入るcross入力は
任意時刻で \(\ell_i^P\) 以下である。孤立blockのrectangle marginを
\(M_i^P(s_i)\)、外乱上限を \(e\) とすると、

\[
M_i^P(s_i)\ge e+\ell_i^P\quad(i=1,\ldots,m)
\]

なら、そのrectangle直積は全系でロバスト正不変である。この十分性は \(P\) が
生成時partitionまたは意味論的moduleであることを必要としない。従って誤分割は
certificate違反を必ず生むのではなく、marginの鋭さ、直積表現、計算量、経験的
predictorの較正を変える。

### 3.2 固定predictorの特徴摂動上界

固定standardized ridge predictorを

\[
\widehat y_P=\operatorname{clip}_{[0,1]}\left(
b+\sum_k\beta_k\frac{\phi_k(P)-\mu_k}{\sigma_k}\right)
\]

とする。clipは1-Lipschitzなので、任意の二partition \(P,Q\) について

\[
\boxed{
|\widehat y_P-\widehat y_Q|
\le B_{P,Q}:=\sum_k\frac{|\beta_k|}{\sigma_k}
|\phi_k(P)-\phi_k(Q)|
}
\]

である。これはtask値を使わず計算できる条件付き上界であり、task誤差そのものの
上界ではない。実測予測差、上界 \(B_{P,Q}\)、上界に対する比を保存する。

## 4. 固定設計

- development seed: 2601–2630。
- confirmation seed候補: 2701–2730。development後に判定を固定するまで
  task値を生成しない。
- module size: 2+2+3、dimension 7、diagonal gain 1.5。
- internal gain: 0.025, 0.05。
- maximum inbound bridge strength: 0.01, 0.02, 0.04。
- 各base networkの摂動方向: EXP-2026-018と同じ算法のdirection index 0を
  一つだけ固定し、振幅間で共有する。
- 相対振幅: 0.90, 2.0, 4.0。実振幅は
  \(\epsilon=\kappa r_{part}\)。0.90は保証内対照、2と4は探索域である。
- disturbance bound: 0.12, 0.20。
- task: 4整列符号code、80 step。autonomous searchは500 step、収束tolerance
  \(10^{-9}\)。
- predictor: EXP-2026-016 pilotの固定三model。再fit、特徴選択、penalty変更を
  禁止する。model SHA-256は
  `db0b50a648fb085ca687922a531fab5482af2a134bd01eefc3efe3dd85675a01`。

一phaseは180 base network、540摂動後network、最大1,080 partition比較point、
結合後task challenge 552,960である。推定器がpartitionを返せない場合は
`abstained` として保存し、機能誤差を0補完しない。

## 5. development前判定

toleranceは \(10^{-12}\) とする。

1. `fixed_model`: model hash、model順、feature名が固定値と一致する。
2. `subradius_recovery`: \(\kappa=0.90\) の全180 networkで推定partitionが
   oracleと一致する。
3. `subradius_profile_identity`: 同条件の全disturbanceで全特徴、certificate、
   固定予測がoracleとtolerance内で一致する。
4. `shared_target_identity`: 比較可能な全pointでoracleと推定解析が同じ結合後
   task targetを共有する。
5. `prediction_shift_bound`: 全比較pointで実測固定予測差が
   \(B_{P,Q}+10^{-12}\) 以下である。
6. `factorized_exactness`: 推定partitionでも因子化方向別認証率が有限直積列挙と
   tolerance内で一致する。
7. `certificate_chain`: 推定partitionでも
   \(T\ge R_{rect}\ge R_{dir}\ge R_{global}\) が全pointで成立する。
8. `seed_independence`: family・gain・strengthごとに30 base networkが30個の
   絶対値構造fingerprintを持つ。
9. `task_free_inference`: partition、pair disagreement、保証半径をtask生成前に
   決定し、artifactへ明示する。

## 6. 経験評価とconfirmation固定規則

developmentで次をseed単位に要約する。

- 振幅別の推定成功率、真partition回復率、pair disagreement分布。
- 誤分割条件におけるcomponent featureの最大絶対差とRMSE。
- 固定component predictorの予測差、oracle/inferredの絶対誤差差。
- oracleと推定partitionの方向別・transported certificate差。
- 局所orthant列挙数の比。
- pair disagreementと各機能差のSpearman相関。

development結果から確認対象と数値閾値を選んだ場合、その選択、符号、集約単位、
bootstrap法を本文へ追記してからsource/test manifestを固定する。confirmationでは
未使用seed 2701–2730へ一度だけ適用し、未収束、abstention、陰性結果を除外しない。

## 7. 証拠境界

本実験は7次元2+2+3 generator、独立一様entrywise摂動の一方向、二外乱値、
整列符号task、固定線形predictorに限定する。pair disagreementだけから機能差を
決定論的に上界化できるとは仮定しない。任意partitionでcertificateが安全である
ことは、そのpartitionが効率的、解釈可能、または予測に最適であることを意味しない。
結果は人間脳のmodule誤同定率または発生blueprintの実測証拠ではない。
