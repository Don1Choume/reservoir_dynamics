# EXP-2026-015: 空間局所gateによる生得core保護とplastic reserve維持

状態: pilot前の事前登録  
登録日: 2026-08-02  
対応仮説: `H-BIO-003`, `H-BIO-004`, `H-BIO-005`

## 1. 問い

異なるmodule size、非対称結合、時変確率外乱を持つcore–reserve RNNで、遅い
空間場がreserve-to-core feedbackだけを局所的にgateすると、同じ重み摂動energy
のglobal gain制御より、必須attractor保持とreserve記憶を両立できるか。

## 2. 構成

- core: 3個の対角双安定tanh座標。自律時に8 orthant固定点を持つ。
- reserve: 5次元のseed依存・非対称tanh RNN。
- bridge: 3x5 reserve-to-core feedbackと5x3 core-to-reserve結合を独立生成する。
- field: 8 node chain上の拡散・source・carryの凸結合。
- source: 各core targetに入るgate前feedback loadを局所riskへ正規化する。
- stochasticity: novel入力とpreactivation外乱をseedで生成し、全policyへpairedに
  与える。
- 初期条件: coreの8 orthantすべて、reserveはzero state、fieldはzero state。

module size 3+5、非対称bridge、seedごとに異なる連続絶対値を使う。signed diagonal
conjugacyが絶対値を保存することを利用し、絶対値fingerprintの一意性をtask前の
構造gateにする。

## 3. policy

1. `ungated`: feedbackを常時そのまま使う。
2. `local_field`: field座標でreserve-to-core feedbackの各rowだけをgateする。
3. `global_energy_matched`: local policyと各時刻で同じFrobenius重み摂動energyに
   なるよう、全recurrent matrixを一様縮小する。

global対照のfield時系列はlocal policyで得たfieldを使う。これによりfield source
のpolicy依存を除き、介入scopeだけを比較する。

## 4. 評価量

- 8 core orthantの全時刻符号保持率。
- bistable rectangle certificateを全時刻・全座標で満たすchallenge割合。
- reserveのdelay別linear memoryとtotal capacity。
- local/globalの重み摂動energy差。
- fieldの最小値、最大値、空間分散、sourceからの平均距離。
- raw feedback load、gated load、critical forcingに対するload ratio。
- core保持とreserve容量の二目的Pareto比較。

## 5. pilot

- seed: 1801–1810。
- core gain: 1.5。
- feedback gain: 0.48, 0.64, 0.80。
- stochastic preactivation外乱上限: 0.00, 0.04, 0.08。
- 1 trajectory: washout 80、train 240、test 120、最大delay 6。
- field: diffusion rate 0.20、source rate 0.55、minimum gate 0.05。
- bootstrap: 2,000回、seed固定。

pilotは理論sanityとeffect size推定に使う。confirmationの経験閾値はpilot結果を
見た後に追加するが、confirmation seedへ触れる前に本書へ固定する。

## 6. pilot前に固定する判定

1. 全field stepで各座標が [0, 1] にある。
2. local/global intervention energy差の最大値が 1e-12 以下。
3. local policyのcertificateを満たしたchallengeでcore符号反転が0件。
4. 各feedback gain x noise群で10個の絶対値fingerprintが一意である。
5. reserve recurrenceと両bridgeが全seedで非対称かつ非零である。

## 12. 結論

この構成では、同じFrobenius介入energyでも、全recurrent weightを一様に抑える
よりreserve-to-core bridgeだけを空間的にgateする方が、8個の必須orthantと
5次元reserveの記憶容量を同時に保った。従って少なくとも本familyでは、調節場の
総量だけでなく、作用位置と時間依存scopeがcore–reserve Pareto性能を決める。

ただしglobal対照は単純な一様gainであり、最適制御、低rank制御、学習済みgate
ではない。生物学的には、一次研究が示す局所ion・astrocyte・neuromodulatorの
空間不均一性と整合する工学的構成例に過ぎず、脳が同じ目的関数を最適化している
ことは示さない。

## 13. 証拠境界

本実験が支持できるのは、人工的な3+5次元tanh系における局所field gateの構成的
優位とcertificateである。astrocyte、dopamine、hormone、特定ionが脳内で同じ
最適化を行うこと、人間規模の必要条件、発生過程によるfield配置は示さない。

生物学的着想と数理抽象化の対応は
[空間変調場による機能core保護](../theory/spatial-modulation-fields.md)に記録する。
