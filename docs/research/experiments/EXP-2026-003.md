## 1. 問い

多次元tanh RNN

\[
\boldsymbol{x}_{t+1}
=
\tanh\left(
W\boldsymbol{x}_t+\boldsymbol{b}_{\mathrm{in}}u_t
\right)
\]

について、次の三量を同一個体・同一入力で測定した。

1. 一つの応答軌道に沿った最大条件付きLyapunov指数
2. 複数初期状態間のtail replica RMS距離
3. 線形読み出しによる遅延入力記憶容量

検証対象は次の三点である。

- 負の最大条件付き指数だけでは、大域的な入力応答一意性を保証しない。
- 入力gainは、同期を回復させる一方で飽和により記憶を損ない得る。
- 記憶容量は、単純に「不安定性境界へ近いほど高い」とは限らない。

## 2. 事前規定

- state dimension: 8
- recurrent gain: `0.6, 0.9, 1.2, 1.5`
- input gain: `0.1, 0.5, 1.5`
- trial seed: `11, 29, 47`
- recurrent kernel: seedごとに生成した直交行列をrecurrent gainでスケール
- input direction: seedごとの単位ベクトルをinput gainでスケール
- input: seedごとの一様分布 \(U[-1,1]\)
- initial replicas: zero、all-minus、all-plus、交互符号の4状態
- washout: 200
- training steps: 800
- testing steps: 400
- maximum delay: 12
- tail window: 100
- synchronization tolerance: \(10^{-7}\)
- ridge: \(10^{-8}\)

## 3. 指標

接ベクトルは

\[
\boldsymbol{v}_{t+1}
=
D_tW\boldsymbol{v}_t,\qquad
D_t=\operatorname{diag}(1-\boldsymbol{x}_{t+1}^{\odot2})
\]

で発展させ、各時刻で正規化した。最大有限時間条件付き指数は

\[
\widehat{\lambda}_{\max}
=
\frac{1}{T-W_0}
\sum_{t=W_0}^{T-1}
\log\|D_tW\boldsymbol{v}_t\|_2
\]

とした。

遅延 \(k\) の線形記憶容量は、独立test区間上の入力
\(u_{t-k}\) と線形予測値の相関係数二乗とし、12遅延の総和を報告した。

## 7. 主要結果

### 結果A: 局所指数と大域同期は高次元でも分離した

36条件中24条件が同期した。非同期12条件のうち9条件では最大条件付き指数が
負だった。従って、1本の軌道に沿う局所的な摂動減衰だけでは、異なる吸引域に
残るreplicaを検出できない。

特に `recurrent=1.5, input=0.1, seed=11` は、

- top CLE: -0.4020
- tail replica RMS: 1.0426
- linear memory capacity: 6.7551

だった。一つの吸引域内では高い遅延再構成能力を示しても、初期状態を跨いだ
応答一意性はない。これは「局所的な計算能力」と「大域的に利用可能な計算
能力」を区別する必要性を示す。

### 結果B: 強い入力は同期を回復した

`recurrent=1.2, 1.5` では、input gain 0.1と0.5の全12条件が非同期だった。
input gain 1.5では同じrecurrent gainの全6条件が同期した。

ただし、同期の回復は常に記憶容量最大化を意味しない。例えば
`recurrent=0.6` の平均容量は、input gainを0.1から1.5へ上げると
7.9928から6.0083へ低下した。入力による収縮とtanh飽和の代償と解釈できる。

### 結果C: 今回はedge近傍が最良ではなかった

最大の単一seed容量は `recurrent=0.6, input=0.1, seed=29` の8.0688だった。
最良のseed平均も `recurrent=0.6, input=0.1` の7.9928である。

全36条件でtop CLEと記憶容量の標本相関は -0.6732、同期条件だけでも
-0.5371だった。今回の直交核と有限遅延課題では、指数を0へ近づけることより、
十分な再現性と線形モード保持が有利だった。

この相関はparameter sweep内の交絡を含み、因果効果ではない。

## 8. 証拠境界

### ローカル再現

- 多次元tanh RNNでも負の局所指数とreplica非同期が共存した。
- 強い入力により大域収縮保証外の全seedで同期が回復した条件があった。
- 同期回復と記憶容量の間にtrade-offが現れた。

### pilot所見

- このnetwork familyでは、edge近傍より強く収縮する条件の記憶容量が高かった。
- 非同期でも一つの吸引域に限定したreadoutは高容量を示す場合があった。

### 未検証

- 3 seedの所見が30 seed以上で維持されるか
- 非直交、疎、非対称、学習済みRNNへの一般化
- 非線形IPC、未知task性能、アトラクタatlasとの対応
- 有限test標本による容量の正方向bias
- input gainそのものと同期状態の因果効果の分離
