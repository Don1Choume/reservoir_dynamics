# EXP-2026-014: 弱いmodule間結合による積則残差

状態: pilot事前登録済み、未実行  
登録日: 2026-08-01  
親実験: EXP-2026-013

## 1. 問い

異質な独立2+2 node moduleで厳密に0だったtask積則残差は、弱いmodule間結合
によりどの程度生じるか。また、独立moduleのcomponent rectangleを結合後へ
移送するcertificateと、結合infinity normだけを用いるmargin損失下界は、
結合後の有限時間符号保持率の下界を保つか。

## 2. 対象系

EXP-2026-013と同じ `modular_heterogeneous` のblock diagonal行列を \(W_0\)
とする。node `(0,1)` と `(2,3)` が二moduleである。独立乱数
`random.Random(1_000_003 + trial_seed)` から \(c_0,c_1\in\{-1,1\}\) を
module index順に生成し、

\[
C_{0,2}=C_{2,0}=c_0,\qquad
C_{1,3}=C_{3,1}=c_1
\]

以外を0とする。結合後は

\[
W_\varepsilon=W_0+\varepsilon C
\]

であり、\(\|W_\varepsilon-W_0\|_\infty=\varepsilon\) である。

- dimension: 4
- diagonal gain: 1.5
- internal global gain: 0.05, 0.07
- disturbance bounds: 0.08, 0.12, 0.16, 0.20
- autonomous search: 初期値 \(0.9s\)、500 step、収束tolerance \(10^{-9}\)
- task: 全16 orthant、全16一定corner外乱、100 step符号保持

追記する。

## 4. Confirmation母集団

Pilotで最大strength 0.04でも全点の積則残差が0の場合だけ、confirmationを

本IDのgridを拡大しない。

## 5. 構造gate

task値を生成する前に、各seed・internal gain・strengthについて次を検査する。

1. strength 0ではweakly connected componentが `(0,1)`, `(2,3)` である。
2. 正のstrengthでは全4 nodeが一componentになる。
3. cross perturbationのinfinity normが指定strengthと \(10^{-12}\) 以内で一致する。
4. 各internal gain・strengthのraw 30 networkが符号対角共役で30 classになる。
5. base内部module coupling magnitudeのunordered pairにseed重複がない。

不成立ならtaskを実行しない。generatorを変更する場合は新しい実験IDを用いる。

## 6. 評価量

各seed・internal gain・strength・disturbanceで次を保存する。

- coupled full raw fixed-point count
- isolated module raw countの積
- coupled full task retention \(T_\varepsilon(e)\)
- isolated product retention \(T_1(e)T_2(e)\)
- signed residual \(\Delta_T=T_\varepsilon-T_1T_2\) と絶対値
- coupled common-boundary certified fraction
- isolated component certified fraction
- actual cross符号を使うtransported rectangle certified fraction
- \(e+\varepsilon\) でmarginをshiftするnorm-shifted certified fraction
- 各certificateとtask retentionのgap
- coupled fixed pointが移送rectangle内にあるorthant割合

## 7. Pilot前に固定する判定

誤差toleranceは \(10^{-12}\) とする。

1. `structure_gate`: 第5節を満たす。
2. `zero_coupling_recovers_product`: strength 0の全点でraw count積とtask積則が
   成立する。
3. `transported_certificate_lower_bound`: 全点で
   \(T_\varepsilon(e)\ge R_{\mathrm{rect}}(e)\)。
4. `norm_shifted_certificate_lower_bound`: 全点で
   \(T_\varepsilon(e)\ge R_{\mathrm{shift}}(e)\)。
5. `transported_dominates_norm_shifted`: 全点で
   \(R_{\mathrm{rect}}(e)\ge R_{\mathrm{shift}}(e)\)。

判定2は零結合実装sanity、判定3–5は
`theory/weak-module-coupling.md` の十分条件に対応する。経験的な残差検出判定と
coupling-response判定は、pilot要約だけを見て固定し、confirmation前に追記する。

## 8. 再現性手順

1. rectangle certificate、cross generator、structure gate、runnerをTDDで実装。
2. Pilot前に全test suiteとbranch coverage 80%以上を確認する。
3. `src/**/*.py` と `tests/**/*.py` のmanifest SHA-256を固定する。
4. pilotを一度だけ実行しartifactへ保存する。
5. 経験判定を追記し、confirmation構造gateをtask前に別artifactへ保存する。
6. 再度全testとmanifestを固定し、confirmationを一度だけ実行する。

## 9. 証拠境界

本実験は4次元tanh RNN、対称な二bridge結合、一定corner外乱、100 step符号保持
に限定する。積則残差と結合normの関係を任意topology、確率外乱、高次元、
生物学的networkへ一般化しない。とくに task retention は有限challenge集合上の
階段関数なので、滑らかな摂動展開を仮定しない。
